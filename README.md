# Sistema de Gestión de Tareas

Caso Práctico 101 — *Fundamentos de Ingeniería de Software* (MIS 101)
Maestría en Ingeniería de Software — CESUMA Universidad

## Descripción

Aplicación de línea de comandos escrita en Python que permite **crear, editar,
eliminar, listar y filtrar tareas**. Cada tarea tiene nombre, descripción,
fecha de vencimiento y estado (`pendiente`, `en progreso`, `completada`).

## Requisitos

- Python 3.10 o superior
- Sin dependencias externas (solo biblioteca estándar)
